# Melody Master GCSE Feedback Layout Tweak

Updated the main Melody Master app feedback panel only.

## What changed

- Removed the large score headline from the checked-answer feedback panel.
- Removed the “GCSE-style best-fit marking” / “Full GCSE-style credit” headline text.
- Kept the three compact mark boxes and renamed them:
  - GCSE mark
  - Pitch mark
  - Contour mark
- Removed the extra “Mark awarded” tile.
- Removed the extra “Error location” tile.
- Removed the separate contour / interval-size diagnostic boxes from the visible panel.
- Moved the feedback text into one concise feedback tile directly under the three mark boxes.
- Added compact CSS so the feedback panel is designed to fit inside the console without requiring scrolling.

## What did not change

- No gameplay logic changed.
- No drag/drop behaviour changed.
- No score image/audio behaviour changed.
- No Teacher Mode files changed.
- No classroom flow changed.
- The GCSE marking calculation is still present; this update only changes how the feedback is displayed in the main app.
